# M3 单次调用标注 20 条：质量复核

结论：20 次请求均完成，最终对象全部通过结构校验；18 条答案与原参考一致，另 2 条是参考答案有误或不完整。按当前反思训练目标保守复核，建议保留 7 条候选，其余 13 条进入人工复核。7/20 是这批分层样本的人工筛选结果，不是模型数学正确率或全量预计合格率。

- MiniMax-M3；temperature=0.3，top_p=0.95，max_completion_tokens=16384；thinking.type=adaptive，reasoning_split=true。
- endpoint：https://api.minimaxi.com/v1/chat/completions。
- 沿用上一轮 v2 单次调用 prompt/schema，资产逐字节一致，没有根据新题修改提示词。
- 0.6B、4B 各 10 条；各模型按四次采样答对 1/2/3 次分为 4/4/2 条。
- 固定 seed=43，先按哈希排名选题及完整错误轨迹，再调用 teacher。20 个不同题目，每题一条，不与此前 4 条测试重复；排除未知判分题组及截断回答。
- 最大在途请求数 4；每条恰好一次，共 20 次，无重试、无额外评审 API 调用。Perfect 请求 0，未启动全量并发 64 或训练。

## 两条 gold 不一致，不应算作 teacher 算错

1. 三次复合：#p=2p+a，则 #(#(#p))=8p+7a。p=18 且结果为 -4，得到 a=-148/7。三次回代依次为 104/7、60/7、-4，teacher 正确；原参考 -21 则得到 -3，不是 -4。
2. 平方根等于自身：sqrt(x)=x 的完整解集为 {0,1}，两个值均满足原式。原参考只给 0 不完整；teacher 对学生错误排除 0 的修复与最终解集有数学依据。

但上述两条都没有返回约定的 reference_conflict，故先隔离复核，不自动更改 gold 或放入训练。原参考一致率 18/20 不能直接当成 teacher 数学正确率。

## 待复核的主要原因

- 直接泄漏答案：不等式题在反思给出最大值 16；面积题在反思给出正确乘积 45552。
- 反思过早完成关键修复：数列 GCD 题已推导 d_n|401 并指出实现上界的目标；奇函数题给出24，而保留状态已说明最终值为它的相反数。这两条是边界越界，不只是机械匹配数字。
- 题面/假设问题：焦弦题只写 k≠0，未明确 M≠N，字面允许 k=1、M=N、距离0；种子题没描述另外两盆及剩余种子，teacher 却假定未说明的数量为0；抽样题只说随机选择，teacher 将系统抽样当成已知条件。
- 错因解释问题：超平面题最终480正确，但 teacher 声称区域翻倍需要一般位置，这是错误的必要条件。实际只需新超平面切开所有旧区域，本题第一次常数和切片就是非一般位置下翻倍的例子。
- 静默修复：三角形高度题正确答案3，但学生先错配正弦定理的边角对应，teacher 只解释后面的根式加法，却在续推中悄悄换回正确边名。
- 已有状态来源：梯形题等把学生错误前未建立的结论写进 verified_states；另有序列题错因措辞不精确和字面反斜杠n排版问题。

待复核不等于数学全错；包含源题问题、反思职责问题和少数错误解释。具体到每条的标签与依据见 manual_review.json 和 SAMPLES_REVIEWED.md。

## 建议保留的 7 条

- 0.6B：灯的非相邻选择、GCD/LCM 最大值、平方和约束线性方程。
- 4B：抛物线正整数点计数、锐角三角形共圆、蚂蚁净位移、两把锁时间关系。

这里允许不影响数学含义的文风、长度和必要符号修正规则，重点要求没有最终答案泄漏、关键错误推理或未说明的输入条件。正整数点题虽未逐一列举此前全部算术失误，但指出决定性的整数误判和不完整枚举，因此保留为候选。这是人工质量判断，不是所有 prompt 条款逐字满足的证明。

数值巧合不算泄漏：序列题的索引上界1006、抛物线配方的平移量22，虽然恰好等于各题答案，但不是在反思中宣布所求结果。平方根题学生本已得到候选0和1，也不能仅因保留这些候选而判泄漏。

几何题独立验证：令 A=n、B=β。角XCB=90−β，角BXC=90+β/2；O、X在BC同侧，共圆给2n=90+β/2。因此B=4n−180、C=360−5n，全锐角要求54<n<67.5。最大整数67，取B=88、C=25可实现。
