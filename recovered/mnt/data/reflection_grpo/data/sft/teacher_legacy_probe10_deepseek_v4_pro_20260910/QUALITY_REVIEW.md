Prompt：与用户指定的 teacher_legacy_probe4_m3_t03_20260910/requests.json 消息模板逐字核对一致；不是重新设计的 prompt。该模板由 clean/scripts/data/prepare_sft_data.py 的 _teacher_prompt 产生。

模型 DeepSeek-V4-Pro，Paratera，thinking enabled / reasoning_effort high；temperature 请求值 0.3，top_p 0.95，max_tokens 16384，并发 4。每条一次调用，无重试、无第二阶段 API，perfect 调用 0。10 条取自已有 20 条探测题，每模型 k=1/2/3 各 2/2/1 条；不是新题，也不是总体随机正确率估计。

- 10/10 HTTP 200，模型名一致、finish_reason=stop、返回 thinking。
- 10/10 原始 content 能直接解析为符合五字段要求的 JSON，无 Markdown fence；全部 verdict=incorrect。
- 人工可辨认的最终数字 10/10 匹配参考答案；原样本地评分 9/10。第 1 条 JSON 内的单反斜杠被解释为退格控制字符，boxed 损坏，不能把数字匹配说成格式合格。
- 不代表数学及反思质量 100%。有 1 条明显受错误/不完整 gold 诱导；另有题意约定、首错定位及状态来源问题。
- 总 token 63852（prompt 13200，completion 50652，后者含 thinking）；未导出生产训练数据，未改写 API 原文。

按当前两阶段训练目标，优先候选 3、4、9、10（4 条）；1、2、6 需题意/格式确认（3 条）；7、8 需反思修订（2 条）；5 拒收（1 条）。这只是本次 10 条的人工分组，不是统计估计，也未实际修改或入库。

共同的风格问题：多数反思仍使用 The student 等第三人称，与 So far I have / However 拼接不自然。中间修正公式允许保留，不采用“出现新公式就拒收”的过严标准。

## 建议，尚未修改 prompt

保留五字段、单次调用。优先删除“GOLD_ANSWER 权威且不要质疑”的硬性限制，允许 unusable 表示参考答案错误、条件不足或歧义；明确首错前状态范围与第一人称；明确 JSON 反斜杠转义。候选题中存在 gold 问题时，perfect 本地正确评分也不保证数据无误。

完整题目、学生回答与 API 最终 JSON 见同目录 SAMPLES_REVIEWED.md；原始请求见 requests.json，原始响应见 calls。所有建议均未改写原始输出。
